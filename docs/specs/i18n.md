# Spec: Internationalization

## Goal
English primary at `/`, Portuguese at `/pt/`, both SSG-prerendered with reciprocal hreflang.

## Acceptance criteria
- [ ] `/` serves English (`lang="en"`)
- [ ] `/pt/` serves Portuguese (`lang="pt-BR"`)
- [ ] Reciprocal `hreflang` for `en`, `pt-BR`, and `x-default` (x-default → `/`)
- [ ] Distinct localised meta title/description and OG per locale
- [ ] Language toggle preserves scroll position / current act when navigating
- [ ] No client-only language switch that leaves the other locale unprerendered
- [ ] Writing section shows Portuguese Medium titles/excerpts with visible "in Portuguese" / "em português" language chip (honest middle option)

## Routes
| Path | Locale | Document lang |
|------|--------|---------------|
| `/` | en | en |
| `/pt/` | pt | pt-BR |
