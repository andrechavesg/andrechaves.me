# Spec: Internationalization

## Goal
English primary at `/`, Portuguese at `/pt/`, both SSG-prerendered with reciprocal hreflang.

## Acceptance criteria
- [x] `/` serves English (`lang="en"`)
- [x] `/pt/` serves Portuguese (`lang="pt-BR"`)
- [x] Reciprocal `hreflang` for `en`, `pt-BR`, and `x-default` (x-default → `/`)
- [x] Distinct localised meta title/description and OG per locale
- [x] Language toggle preserves current act via hash (`alternatePath` + hashchange)
- [x] No client-only language switch that leaves the other locale unprerendered
- [x] Writing section shows Portuguese Medium titles/excerpts with visible "in Portuguese" / "em português" language chip (honest middle option)

## Routes
| Path | Locale | Document lang |
|------|--------|---------------|
| `/` | en | en |
| `/pt/` | pt | pt-BR |
